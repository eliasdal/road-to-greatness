# Road to Greatness — 82-0 Draft

A browser recreation inspired by the 82-0 game loop described by the supplied gameplay guide. It uses original UI/code and a curated historical NBA player dataset.

## Game loop
Play → choose Classic or HoopIQ → Spin team + decade → choose a player → assign PG/SG/SF/PF/C → repeat for 5 rounds → simulate 82 games → final record.

## Included mechanics
- 5-round historical NBA draft
- Random franchise + decade
- One Team Skip and one Decade Skip
- Classic mode with PPG/RPG/APG/SPG/BPG
- HoopIQ mode with hidden stats
- Position assignment and locked picks
- Five-player starting lineup
- 82-game season simulation
- Non-linear win projection
- Final record and recent game results
- Local browser save

## Deploy
Put `index.html`, `style.css`, `app.js`, and `data.js` in the root of a GitHub Pages repository. The site is static and needs no build step.

The player data is a curated gameplay dataset, not an official NBA database or licensed copy of another game's proprietary data/assets.
