# Perfect Season — NBA 82-0 / NFL 17-0

A starter browser franchise simulator inspired by the concept of chasing a perfect season.

## Run locally
Open `index.html` in a browser.

## GitHub Pages / Netlify
Upload the project files to a GitHub repository. The important file is `index.html` at the repository root.

If you download the ZIP, **do not upload the ZIP as the website itself**. Extract it first, then upload the files/folders inside it. GitHub can store ZIP files, but GitHub Pages/Netlify need the actual site files (especially `index.html`) available as the deployed site's root.

## Current features
- NBA and NFL modes
- All 30 NBA teams and 32 NFL teams
- Franchise selection
- Game-by-game simulation
- NBA 82-game goal
- NFL 17-game goal
- Schedule
- Standings
- Record, games remaining, win streak
- Browser localStorage save
- Responsive dark sports UI
